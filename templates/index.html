How the integration works

One script tag. The widget builds itself inside a shadow root, so this page's CSS and the widget's CSS never collide.

Isolated styling

Shadow DOM keeps host styles out. Drop it on WordPress, Shopify or a static page and it looks identical.

Cross-origin ready

The API sends CORS headers, so the bot can be hosted separately from the site it serves.

Keyboard and screen reader

Escape closes it, focus returns to the launcher, and the log is announced with aria-live.

Try these in the widget

  • "how long does shiping take" — misspelling, still matches
  • "can I send it back" — no keyword overlap with the training pattern
  • "do you sell kayaks" — out of scope, falls back instead of guessing
  • "agent" — escalates to a human
